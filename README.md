# Бой в клетку

Браузерный файтинг с человечками из палочек. Создаёшь своего бойца (имя, цвет, шапка, характеристики, суперсила) и проходишь турнир против девяти соперников: 9 туров «каждый с каждым», потом полуфинал и финал для четырёх лучших.

## Управление

| Действие | Клавиши |
| --- | --- |
| Ходьба | `A` `D` или `←` `→` |
| Прыжок | `W` или `↑` |
| Удар | `J` или `Z` |
| Пинок | `K` или `X` |
| Блок (держать) | `L`, `C`, `S` или `↓` |
| Суперсила | `Пробел`, `V` или `I` |
| Пауза | `Esc` или `P` |

На телефоне под ареной появляются сенсорные кнопки, удобнее играть горизонтально.

## Запуск

Сборка не нужна: откройте `index.html` в браузере или поднимите любой статический сервер в корне репозитория, например `python3 -m http.server`.

## Код

- `js/data.js` — суперсилы, соперники, константы
- `js/draw.js` — рисование человечков, позы, арена
- `js/fight.js` — боец: движение, удары, суперсилы
- `js/match.js` — бой: снаряды, эффекты, интерфейс на арене
- `js/ai.js` — управление игрока и компьютерных соперников
- `js/cup.js` — турнир: расписание, таблица, плей-офф
- `js/ui.js` — экраны, сохранение, главный цикл
